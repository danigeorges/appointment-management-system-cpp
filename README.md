# 📅 Appointment Management System (C++)

## 📌 Overview
A console-based appointment scheduling system developed in C++ using a Binary Search Tree (BST) data structure to organize and manage appointments efficiently.

## 🚀 Features
- Add and manage appointments
- Search for appointments
- Delete appointments
- Display appointments using tree traversal
- Priority-based appointment organization

## 🧠 Concepts Used
- Binary Search Trees (BST)
- Recursion
- File Handling
- Object-Oriented Programming (OOP)
- Dynamic Memory Management

## 🛠️ Technologies
- C++

## 📈 Future Improvements
- Add graphical user interface (GUI)
- Improve data persistence
- Add appointment editing and notifications
